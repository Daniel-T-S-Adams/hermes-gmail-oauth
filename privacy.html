Privacy Policy

This application is a private, single-user Gmail integration for a personal AI assistant.

Data Access

The application accesses Gmail messages using the gmail.readonly OAuth scope.

Data Usage

Email content is processed to search, summarise, and prepare suggested replies.

Data Storage

OAuth credentials are stored securely on a private server. Suggested replies may be saved as local Markdown files.

Data Sharing

Email content may be processed by the AI model provider configured for the assistant. It is not sold or used for advertising by this integration.

Permissions

This application does not request permission to send, modify, or delete Gmail messages.
